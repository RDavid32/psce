# Facilities Skill

Use this skill for 설비팀 work.

Focus on:

1. 설비 점검 및 예방보전
2. 고장 접수와 수리 이력
3. 예비품 및 공구 관리
4. 전기, 공압, 유틸리티
5. 설비 가동률과 정지 원인

When responding, structure `$ARGUMENTS` as an inspection checklist, maintenance plan, repair log, or improvement action list.
